# VitalCheck

מעקב אחר תאריכי תוקף ומלאי של ציוד רפואי — לתיק כונן, אמבולנס או מרפאה.

## שימוש

1. פתח את האתר בכרום או באדג' במחשב
2. לחץ "התחלה חדשה" ליצירת קובץ נתונים חדש, או "יש לי כבר קובץ" לפתיחת קובץ קיים
3. הוסף פריטים: שם, קטגוריה, תוקף (חודש/שנה) וכמות (לא חובה)

כל שינוי נשמר אוטומטית בקובץ שפתחת, ואין צורך ללחוץ על שמירה.
השורה שמעל הטבלה מציגה תמיד לאיזה קובץ הנתונים מחוברים.

## תכונות

- שמירה אוטומטית של הנתונים לקובץ מקומי (מומלץ בתיקיית Dropbox / Google Drive)
- צביעה לפי דחיפות התוקף: פג תוקף / פג החודש (אדום), פג בחודש הבא (כתום),
  פג בעוד חודשיים (צהוב), תקף (ירוק), ללא תוקף (אפור)
- שדה כמות לכל פריט (לא חובה)
- חיפוש, סינון לפי קטגוריה, ובחירה של כמה סטטוסים יחד (רשימה עם תיבות סימון)
- ניהול קטגוריות (מהשורה האחרונה ברשימת הקטגוריות)
- תפריט "קובץ": הדפסה / PDF, שמירה כקובץ חדש, פתיחת קובץ אחר, התחל מהתחלה
- דוח הדפסה / PDF: טבלה מחולקת לפי דחיפות, קריאה גם בהדפסה בשחור-לבן
- "קבצים אחרונים": עד 8 קבצים שנפתחו לאחרונה, נפתחים בלחיצה בלי לחפש בתיקיות; מעבר בין תיקים מתפריט "קובץ"
- "שליחת דוח": קובץ PDF מלא שנוצר בדפדפן, עם טיוטה מוכנה ב-Gmail, שיתוף, או העתקת סיכום קצר לוואטסאפ
- גיבוי אוטומטי בדפדפן (עד 15 גיבויים אחרונים) ושחזור מגיבוי
- "שמירה כקובץ חדש" — שמירת הנתונים שעל המסך לקובץ, למשל אחרי שחזור מגיבוי
- אזהרה לפני כל פעולה שעלולה למחוק נתונים שלא נשמרו בקובץ
- עובד במחשב עם כרום או אדג' (בספארי ובטלפון אין שמירה אוטומטית לקובץ)

## הנתונים

הנתונים נשמרים רק בקובץ JSON במחשב של המשתמש ובגיבוי בדפדפן שלו.
שום מידע לא נשלח לשרת.
