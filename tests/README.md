# בדיקות VitalCheck

מריצים מתיקיית הפרויקט (השורש), עם Playwright המותקן בסביבה:

```
node tests/<file>.js <תיקייה-לקבצים-זמניים>
```

| קובץ | מה בודק | נוגע בענן אמיתי? |
|---|---|---|
| cloud-sim.js | זרימת ענן מלאה מול דרופבוקס/דרייב מדומים (התחברות, שמירה, התנגשות, בלי אינטרנט, מפתח שפג, ניתוק) | לא |
| cloud-integrity.js | שלמות נתונים: שמות בעייתיים, שמירה איטית, תקלות שרת, מעבר בין תיקים, שתי לשוניות, קובץ פגום, PDF/אקסל. ארגומנט שני: שם מכשיר ("Pixel 7") או "" למחשב | לא |
| real-dropbox.js / real-gdrive.js | אותם תרחישים מול השרתים האמיתיים. דורש מפתח בדיקה שהוזן לסביבה (request_credential). נוגע **רק** בקבצים ששמם מתחיל ב-VCTEST ובודק בסוף שקבצי המשתמש לא השתנו | כן |
| local-*.js | מצב קובץ במכשיר (הגנה מדריסה, חידוש, סל מחזור, אקסל ועוד) | לא |
| cloudmock.js | הדמיית שרתי דרופבוקס וגוגל דרייב + הגשת האתר מהדיסק בכתובת האמיתית | — |

כל סדרה מדפיסה PASS/FAIL לכל בדיקה ובסוף ALL PASSED או מספר הכישלונות.
